Sensores

Valor medido, valor esperado pelo gêmeo digital no mesmo instante e diferença. Linha cheia = campo, tracejada = gêmeo. Clique para ampliar.

Fonte de dados

Em operação real, o SCADA (ou um gateway OPC-UA / MQTT / Node-RED) envia as leituras para POST /api/telemetria. Sem SCADA conectado, use o simulador: ele gera a "rede real" a partir do cadastro, com ruído de medição e, se quiser, um vazamento escondido para o gêmeo encontrar.

Formato da integração com o SCADA 
POST http://localhost:8765/api/telemetria
Content-Type: application/json

[{"elemento": "S1",     "grandeza": "pressao", "valor": 19.6, "ts": "2026-10-24T07:15:00"},
 {"elemento": "T_S1_C", "grandeza": "vazao",   "valor": 11.8, "ts": "2026-10-24T07:15:00"},
 {"elemento": "R1",     "grandeza": "nivel",   "valor": 3.42, "ts": 1792833300}]

elemento = código do cadastro · grandeza: pressao (mca; em válvula/bomba = jusante), vazao (L/s), nivel (m) · ts: ISO ou segundos Unix. As leituras ficam em *_telemetria.sqlite ao lado do cadastro.
